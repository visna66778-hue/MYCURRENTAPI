# Миникошелёк путешественника

Telegram-бот на Python для учёта расходов в поездках. Бот помогает создавать и переключать путешествия, следить за балансом в двух валютах и просматривать историю расходов. Курсы валют и конвертация запрашиваются у `api.exchangerate.host`, а данные хранятся в локальной SQLite-базе.

## Возможности

- Создание путешествия по стране отправления и стране назначения. Валюты определяются по локальному справочнику в `countries.py`.
- Получение курса и конвертация через `api.exchangerate.host`. Курс можно подтвердить или задать вручную.
- Несколько путешествий для пользователя, выбор активного путешествия и отдельные балансы.
- Ввод расходов суммой в валюте страны пребывания. Бот показывает пересчёт в домашнюю валюту, предлагает категорию и записывает расход только после подтверждения.
- Категории расходов: еда и кафе, жильё, транспорт, покупки, развлечения и экскурсии, здоровье, связь и интернет, прочее.
- Просмотр баланса в обеих валютах.
- История расходов за день, неделю, месяц или всё путешествие; просмотр операций и итогов по категориям, а также общей суммы расходов.
- Inline-меню для перехода между разделами.

## Технологии

- Python
- [pyTelegramBotAPI](https://pypi.org/project/pyTelegramBotAPI/) — Telegram Bot API
- [requests](https://pypi.org/project/requests/) — HTTPS-запросы к API курсов валют
- [python-dotenv](https://pypi.org/project/python-dotenv/) — загрузка настроек из `.env`
- `sqlite3` — встроенная библиотека Python для локальной базы данных
- `api.exchangerate.host` — текущие курсы и конвертация валют

## Структура проекта

```text
MYCURRENTAPI/
├── bot.py            # Telegram-бот, меню, команды и диалоги
├── current_api.py    # запросы к api.exchangerate.host и конвертация валют
├── countries.py      # локальное соответствие стран и кодов валют
├── database.py       # SQLite: путешествия, балансы и расходы
├── requirements.txt  # зависимости Python
├── .env.example      # пример переменных окружения без реальных секретов
├── .gitignore        # исключает .env, базу и служебные файлы из Git
└── wallet.sqlite3    # локальная база данных, создаётся при запуске
```

## Установка

Установите Python и создайте виртуальное окружение в корневой папке проекта:

```powershell
python -m venv .venv
```

Активируйте его в Windows PowerShell и установите зависимости:

```powershell
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Для командной строки Windows используйте `.\.venv\Scripts\activate.bat`.

## Настройка `.env`

Создайте файл `.env` в корневой папке, скопировав `.env.example`, и укажите свои значения:

```env
TELEGRAM_BOT_TOKEN=ваш_токен_telegram_бота
EXCHANGE_API_KEY=ваш_ключ_api_exchangerate_host
```

Бот использует переменные `TELEGRAM_BOT_TOKEN` и `EXCHANGE_API_KEY`. Не добавляйте реальные значения в Git: `.env` уже внесён в `.gitignore`.

## Запуск

Из корневой папки проекта и с активированным виртуальным окружением выполните:

```powershell
python bot.py
```

Остановить бота можно сочетанием `Ctrl+C`. При первом запуске SQLite создаст или обновит нужные таблицы в `wallet.sqlite3`.

## Команды бота

- `/start` или `/help` — открыть главное меню.
- `/newtrip` — создать путешествие.
- `/switch` — выбрать активное путешествие.
- `/balance` — показать баланс активного путешествия.
- `/history` — открыть историю расходов.
- `/setrate` — изменить курс активного путешествия.
- `/cancel` — отменить текущий диалог.

Эти разделы также доступны через inline-меню. Вне диалогов сообщение с положительным числом воспринимается как сумма расхода в валюте активного путешествия.
